# ⚠️ 群友反馈复核：本机数据支持了其中**三**条

> 来源：2026-09-26 群里有人用了本 preset 后反馈。**这是外部真实使用反馈，比我的实验更值钱。**
> 本文件用**本机会话日志**（¥0，不跑新实验）逐条核对哪些成立、哪些不成立。

---

## 反馈原文（要点）

1. **「后端能力下降了，写他的构式写不明白，想的是很快」**
2. **「不查证都是错的。说是 let me 会仔细的一点点查反而能作对」**
3. **「难度上来就很难受」**
4. **「we need 稳不住，让他做任务跑了 300 多 M，就变回 let me 了」**
5. **群友猜测**：是难度？还是工具次数？

---

## ✅ 成立：反馈 2（不查证）—— 与我的实验完全吻合

我在马里奥 A/B 里独立测出过同一件事（**互不知情，两个来源撞上了**）：

| 指标 | 标准模式 | 本模式 |
|---|---:|---:|
| 首次写代码前**真正查证**次数（中位） | **30** | **6** |
| `web_search` / `web_fetch` | 1 / 5 | **0 / 0** |
| 思考里「猜疑词」密度（每千字符） | 0.01 | **0.96** |

**群友说"不查证都是错的"、"let me 会仔细查反而能作对"——这正是我标为「未定」的那一点，
而他用真实任务给出了答案：在需要精确性的任务上，少查证 = 做错。**

→ **该把我的「未定」改成「已被真实使用证实（至少在某些任务上）」。**

## ✅ 成立：反馈 4（稳不住）—— 本机数据强力支持

扫描全部 **14 个真实 we-need 会话**，统计"思考段开头是英文"（= 漂移）的比例：

| 工具调用数 | 会话数 | 英文开头（中位） |
|---|---:|---:|
| < 100 | 7 | **10%** |
| 100–200 | 1 | 3% |
| **200–300** | 4 | **46%** |
| 300+ | 2 | 30% |

**相关系数 r = 0.748**（工具调用数 vs 漂移比例）。

**不是渐变，是断崖**：拐点在 **约 150–200 次工具调用**。

**并且在单个会话内部同样成立**（以工具调用 448 次的最大会话为例）：

| 已发生工具数 | 英文开头 |
|---|---:|
| 0–49 | **7%** |
| 50–99 | 15% |
| 100–149 | 36% |
| 150–199 | **69%** |
| 200+ | 33–100% |

→ **群友的观察准确**：任务一大/跑久了，风格就守不住。
→ **"工具次数"这个猜测，本机数据支持（r=0.748）。**

## ⚠️ 部分成立：反馈 1（能力下降）

**能说的**：本模式**确实不查证、且更早下手**（见上），在需要精确性的任务上会做错。
**我自己的实验里**：通过率**没测出差异**（四种任务类型）——但那四种任务都是
**"有明确 spec、不需要外部精确资料"** 的，所以测不出。

**不能说的**：不能说"能力普遍下降"。**正确表述是**：
> **在需要查证/精确性的任务上，本模式可能因"少查证"而做错；在自包含任务上未测出差异。**

## ❓ 未验证：反馈 3（难度）

「难度」和「工具次数」在本机数据里**高度混淆**（难任务自然工具多），
**无法分离**。但"工具次数"是**可操作、可量化**的那个（r=0.748）。

## ✅ 成立：反馈 5（300M 那个量级）

本机最大的 we-need 会话是 121MB 累计输入 token（448 次工具调用）→ 漂移 30%。
**与群友"跑了 300 多 M 就变回 let me"的量级一致。**

---

## 结论：给用户的**诚实建议**

### 什么时候该用本模式
- **短任务**（≲100 次工具调用）：风格守住（漂移 10% 以内），**快 2.4–3.8×、省约一半**。
- **自包含任务**（不需要查外部资料）：不受"少查证"影响。

### 什么时候**不该**用
- **长任务**（>150–200 次工具调用）：**风格会断崖式失守**（漂移 30–50%）。
- **需要查证/精确性的任务**（API 对接、版本行为、精确规格）：
  **本模式会少查证、更容易做错**。这类任务**用标准模式（Let me 系）反而更对**。

### 该写进 README 的
这两条**都是"限制"，不是"卖点"**，必须写清楚，否则用户会踩坑。

## 复现命令（¥0）

```sh
cd <路径> && python3 - <<'PY'
import glob,os,subprocess,json,re,sys
sys.path.insert(0,'<实验目录>')
from drift import blocks_of
CJK=re.compile(r'[\u4e00-\u9fff]')
rows=[]
for p in glob.glob(os.path.expanduser('~/.dsh/sessions/*/session-*/session.v3.jsonl.zstd')):
    raw=subprocess.run(['zstd','-d','-c','--',p],capture_output=True).stdout.decode('utf-8','replace')
    used=None; tc=0
    for line in raw.splitlines():
        line=line.strip()
        if not line: continue
        try: j=json.loads(line)
        except: continue
        if j.get('type')=='agent-preset/selected': used=j['data'].get('agentPreset')
        elif j.get('type')=='tool/call': tc+=1
    if used!='we-need': continue
    bs=blocks_of(p)
    if len(bs)<10: continue
    en=sum(1 for b in bs if not CJK.search(b['text'][:40]))
    rows.append((tc,en/len(bs)))
for tc,pct in sorted(rows): print(f'工具{tc:4d} → 英文开头{pct*100:3.0f}%')
PY
```
