# 马里奥 A/B 实验：方法坑记录（给下一棒）

> 本文件记录**这次实验自己踩的坑**。比结论更容易被重踩，所以单独放一份。

## ⚠️ 坑 1（最严重）：用正则从 YAML 里抠 persona，污染了 34%

**症状**：we-need 臂跑的不是线上 preset。

**根因**：`make-arms.py` 第一版用正则
`(?=^\s{0,6}\w+:)|(?=^-\s*id:)` 截取 `persona.config.prefix` 块。
temperature 行前的注释块（`agent.cordis.yml:89-123`）里那些 **0 缩进的 `# ...`**
被当成"未缩进的键"，匹配提前终止 → 注释被吞进 persona；
且 `cut = min(indents)` 因此变成 0 → persona 正文保留 6 空格缩进。

**实测影响**：
| | 长度 | sha1 |
|---|---:|---|
| arm 实际的 personaPrefix | 3898 | 9a4a655787e3 |
| **真实 persona（YAML 解析）** | **2253** | b900581c39 |
| 多出来的污染 | **1639 字符**（35 行是 `#` 注释） | |

污染内容里有**我自己的实验笔记**：「它宣称的 1.93× 收益已被本机实测证伪」
「能把思考压短约 21%」——这些文字**直接讨论"思考长度"**，
与本次要测的效率/漂移指标正面冲突。所有 20 个早期 run 全部作废。

**⭐ 更该记住的教训（元层面）**：
我当时还写了个"校验"脚本，声称 arm 与真实 preset **"逐字节相同 ✅"**——
**但那个校验用的是同一个正则**，等于自己证明自己。
**循环论证看起来和验证一模一样。**
正确做法：换一条**独立路径**（这里用真 YAML 解析 + 线上会话的 system/message 对照）。

**修法**：`extract_persona()` 改用 `yaml.load_all` + 为 `!!js` 注册
multi-constructor。修完独立验证：arm persona 与线上 prompt 的 persona 正文
**前 2197 字符完全一致**。

## ⚠️ 坑 2：退化循环检测漏判（正则被换行打断）

**症状**：`weneed/run3` 的 142k 字符段，检测器报"重复 0 字符"。

**根因**：循环体每句之间夹着 `\n\n`，正则 `(.{1,20}?)\1{3,}` 被换行截断。

**修法**：先 `re.sub(r'\s+','',t)` 去空白再找重复。修完同一段测出 **61,336 字符**重复。

## ⚠️ 坑 3：中文率分母口径不一致（放大 2.4 倍）

**症状**：中文占比被系统性高估。

**根因**：分子数**汉字个数**，分母却是 `[A-Za-z]{2,}` 的**词块个数**（findall 数的是"有几个词块"）。
实测 `'我们看看这'*10 + 'abcdefghij'*7` → 报 0.980，真实字符占比 0.417。

**修法**：`LAT` 改成 `[A-Za-z]` 按字符数。修完实测 0.417 ✓（并与手工计数交叉核对）。

## ⚠️ 坑 4：判卷器对相对路径全报 LOAD_FAIL

**根因**：`find_html` 返回相对路径，`render_judge` 拼出 `file://runs/...`（无效 URL）。
**修法**：`find_html` 里 `resolve()`。

## ⚠️ 坑 5：判卷器把开发辅助页当入口

**根因**：`'tools/' in rel` 匹配不到 `tools/map.html`（无斜杠）。
**修法**：按**路径分量**判断（`Path.parts`），并优先 `index.html` 而非"最大 html"。

## ⚠️ 坑 6：会话定位用 `ls -t` 抓错会话

**根因**：并发时"最新会话"可能属于别的臂。日志里 weneed-old 的 run 印出过 base 的会话。
**修法**：按 **cwd** 定位（会话目录名 = cwd 去首斜杠后 `/`→`-`，两侧包 `--`），
并用**差集**（跑前跑后对比）而不是"取最新"。

## ⚠️ 坑 7：两个进程写同一个 run 目录

**根因**：手动起一次 + batch 又起一次。
**修法**：`mkdir` 原子锁（`runs/.lock-<arm>-<n>`）。

## ⚠️ 坑 8：超时设置造成"差别 attrition"

**根因**：`TMO=2400`，但 base 实测要 2209s / 2310s —— 快撞线；
而（被污染的）we-need 臂 220s 就崩。等于**对干活多的臂系统性不利**。
**修法**：超时提到 3600s。
